# PRD review rubric

Review whether the PRD provides enough product intent for the next stage.

Check only material concerns:

1. Problem is distinguishable from the proposed solution.
2. Relevant user or actor is known.
3. Desired outcome is observable.
4. Scope boundaries and appetite are clear enough.
5. Key behavior is defined.
6. Important acceptance can be evaluated.
7. Material dependencies are visible.
8. Assumptions, risks, and unknowns remain explicit.
9. Measurements are useful when measurement is relevant.
10. Important choices have enough rationale to avoid accidental reversal.

Do not require every edge case, future roadmap item, low-level implementation choice, generic NFR section, or perfect prose.
